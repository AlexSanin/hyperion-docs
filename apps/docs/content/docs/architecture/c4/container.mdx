## Overview

The Container diagram shows the high-level shape of the software architecture and how responsibilities are distributed across it. 

**Key:** At this level, we see Archon's internal structure — the services, databases, and messaging infrastructure that power the platform. External systems (CRM, Market Data, Communications) are shown in the [L1 Context diagram](./context).
