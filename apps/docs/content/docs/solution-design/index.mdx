# Solution Designs

Solution designs document the technical approach for implementing major features. Each design includes purpose, scope, risks, and requirements.

## Available Designs

| Feature                                                  | Description                                    | Status |
| -------------------------------------------------------- | ---------------------------------------------- | ------ |
| [Email Ingestion](/docs/solution-design/email-ingestion) | Automatic research capture from email          | Draft  |
| [File Upload](/docs/solution-design/file-upload)         | User-initiated document upload with processing | Draft  |

## Document Structure

Each solution design follows a standard format:

1. **Purpose** — Business goal and high-level architecture
2. **Owners** — Responsible team and stakeholders
3. **Scope** — What's included and excluded
4. **Research** — Technical investigation and findings
5. **Risks & Solutions** — Known risks with mitigations
6. **Additional Documents** — Related architecture docs and ADRs
